جارٍ التحميل…

1أول كلمة للكمبيوتر

الكمبيوتر زي روبوت مطيع: بينفذ أي أمر نكتبهوله. وأمر الكلام اسمه console.log. اللي بنكتبه بين علامتي التنصيص بيتطبع.

💡 كل سطر بينتهي بـ ; زي النقطة في آخر الجملة.
🏆 التحدي: خلّي الروبوت يطبع اسمك، وسنك، وأكلتك المفضلة (٣ سطور).
💡 تلميحكرر console.log("...") ثلاث مرات، وغيّر الكلام اللي جواه.
🔑 الحل
console.log("اسمي سلمى");
console.log("عمري 9 سنين");
console.log("باحب البيتزا 🍕");
🛠️ مشروع الفصل: بطاقة البطل
🎯 مهمتك: غيّر البيانات لبياناتك، وزوّد سطر "حلمي".

2الصناديق السحرية (المتغيرات)

المتغير صندوق عليه اسم، وجواه حاجة. بنعمله بكلمة let.

لاحظ: النص بين تنصيص "..."، والأرقام من غير تنصيص. وتقدر تغيّر محتوى الصندوق في أي وقت: age = 10;

🏆 التحدي: اعمل صندوق اسمه color فيه لونك المفضل بالإنجليزي (مثلاً "gold") وارسم بيه دايرة بالأمر circle(color, 60).
💡 تلميحاكتب اسم لون زي "red" أو "hotpink" بين التنصيص.
🔑 الحل
let color = "hotpink";
circle(color, 60);
🛠️ مشروع الفصل: بطاقة الحيوان الأليف
🎯 مهمتك: اعمل صندوق جديد للوزن weight واطبعه، وغيّر الحيوان لحيوانك.

3الكمبيوتر بيحسب!

الجمع + والطرح - والضرب * والقسمة /. وكمان نقدر ندمج الصناديق جوه الكلام بعلامة الباك-تيك ومعاها ${ }:

🏆 التحدي: الآيس كريم بـ 5 جنيه، وأنت اشتريت 4. اعمل متغيرين price و count، واطبع جملة فيها الإجمالي.
💡 تلميحجوه الجملة اكتب ${price * count}.
🔑 الحل
console.log(`الحساب ${price * count} جنيه 🍦`);
🛠️ مشروع الفصل: فاتورة المطعم
🎯 مهمتك: زوّد حلوى بسعرها وعددها، وحدّث الإجمالي.

4لو ... يبقى (if / else)

الكمبيوتر بياخد قرارات! بنقوله: لو الشرط صح اعمل كذا، وإلا اعمل حاجة تانية. بنقارن بـ > أكبر، < أصغر، === يساوي.

جرب تغيّر 130 لـ 100.

🏆 التحدي: اعمل متغير temperature. لو أكبر من 30 اطبع "الجو حر، اشرب ميه 🥤" وإلا اطبع "الجو جميل، يلا نلعب ⚽".
💡 تلميحاستخدم if (temperature > 30) { ... } else { ... }
🔑 الحل
if (temperature > 30) {
  console.log("الجو حر، اشرب ميه 🥤");
} else {
  console.log("الجو جميل، يلا نلعب ⚽");
}
🛠️ مشروع الفصل: مصحح الدرجات

جديد: else if لما يبقى عندنا أكتر من اختيارين.

🎯 مهمتك: جرّب درجات مختلفة (95، 60، 20)، وزوّد تقدير "جيد" بين 65 و 75.

5التكرار (الحلقات for)

الكمبيوتر مبيزهقش! بدل ما نكتب نفس السطر ١٠ مرات، بنقوله كرره. الحلقة for بتعد من رقم لرقم:

شايف المثلث؟ كل مرة النجوم بتزيد واحدة. وتعالى نرسم دواير ملونة:

🎡 باقي أنواع الحلقات

1) while: بتكرر طول ما الشرط صح. مناسبة لما منعرفش هنكرر كام مرة.

⚠️ لو نسيت n-- الحلقة مش هتقف أبداً! دايماً خلّي الشرط يبقى غلط في الآخر.

2) do...while: بتنفذ الأول وبعدين تسأل. يعني بتشتغل مرة على الأقل.

3) for...of: بتمشي على عناصر مصفوفة (قايمة بين [ ]) واحد واحد.

4) for...in: بتمشي على أسماء خانات كائن (بطاقة بيانات بين { }).

5) forEach: طريقة مختصرة للمصفوفات، بتدّي كل عنصر لدالة.

6) حلقات متداخلة: حلقة جوه حلقة (الخارجية للصفوف، والداخلية للأعمدة).

7) break و continue: continue تتخطى لفة، وbreak توقف الحلقة.

🏆 التحدي: ارسم 10 دواير حمرا في سطر واحد.
💡 تلميحغيّر الرقم 3 إلى 10.
🔑 الحل
for (let i = 0; i < 10; i++) {
  circle("red", 25);
}
🛠️ مشروع الفصل: مدينة النجوم
🎯 مهمتك: اعمل جدول ضرب 7، وزوّد لون في قوس القزح، وكبّر الهرم لـ 6 صفوف.

6الوصفات السحرية (الدوال function)

الدالة زي وصفة كيك: بنكتبها مرة واحدة، وبعدين نطلبها كل ما نحب. الدالة ممكن تاخد مكونات اسمها باراميتر:

وفيه دوال بترجّع نتيجة بكلمة return:

ودالة بترسم! بنكتبها مرة وتتكرر:

🏆 التحدي الكبير: اكتب دالة اسمها square بتاخد رقم وترجّع مربعه (الرقم × نفسه). واطبع square(7).
💡 تلميحجوه الدالة اكتب return n * n; والنتيجة المتوقعة 49.
🔑 الحل
function square(n) {
  return n * n;
}
🛠️ مشروع الفصل: مصنع الأشكال

بنجمع كل حاجة: دوال + حلقات + متغيرات.

🎯 مهمتك: اعمل دالة house بتستخدم triangle وrectangle علشان ترسم بيت، وغيّر الأشكال لإيموجي تحبه.
